Persistence contract

One local writer. A command is acknowledged after journal flush and fsync. A crash before acknowledgment may still leave the command persisted; retrying the same request ID returns the original result. Conflicting reuse is rejected. Recovery replays the snapshot and subsequent complete journal records. A torn final line is removed; complete corrupt records fail closed.

The sandbox caps commands at 5,000. It uses a simple history-copying durability wrapper for clarity, so cost grows with journal length. Benchmark results separate it from the matching core.
